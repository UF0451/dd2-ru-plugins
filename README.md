# Русские плагины для Dragon's Dogma 2

Полная локализация популярных REFramework-модов на русский язык.

## Состав

- **26+ переведённых модов** — UI, настройки, тултипы полностью на русском
- **Исправлены ImGui-ошибки** — PopFont, EndGroup, EndChild, Missing End
- **Кириллический ввод** — поддержка русского текста в текстовых полях (GainItem и др.)
- **Автоопределение пути к сохранениям** — Steam, GSE Saves, Documents

### Основные моды

| Мод | Описание |
|-----|----------|
| DamageNumber | Детальный лог урона с переводом всех типов атак, стихий и реакций |
| ItemBelt | Панель быстрого доступа с русским интерфейсом |
| QuestTracker | Отслеживание квестов с русскими названиями |
| EnemySpawner | Спавн врагов через меню |
| CharacterCustomizer | Кастомизация персонажа |
| GainItem | Добавление предметов с кириллическим поиском |
| и многие другие | |

## Установка

1. Скачай репозиторий
2. Скопируй `dinput8.dll` в папку с игрой (рядом с `DD2.exe`)
3. Скопируй папку `reframework` туда же (слить с существующей, если есть)
4. Запусти игру — в меню REFramework (Insert) появятся настройки на русском

## Важно

- `dinput8.dll` — кастомная сборка REFramework с поддержкой кириллического ввода
- Для не-Steam версий путь к сохранениям: `%APPDATA%\GSE Saves\2054970\remote\win64_save`
- Для Steam: `%USERPROFILE%\Documents\My Games\Dragons Dogma 2\Steam\<SteamID>\`
